# CHOKAPP Admin

Vue 3 + Element Plus admin panel for managing apps, issues, collections, and system settings.

## Tech Stack

- Vue 3 + Composition API
- Element Plus UI
- Vite
- Pinia state management
- Axios + ECharts

## Setup

```bash
npm install
npm run dev
```

Admin panel runs on `http://localhost:5173`. API calls are proxied to `http://localhost:8888`.

## Build

```bash
npm run build
```
